# TechBuilders Restaurant v4

Arabic RTL restaurant digital menu and admin dashboard, using Firebase, Cloudflare Pages and Telegram notifications.

See **START-HERE-AR.md** for the required upgrade and deployment steps.

- Static site build output: `public`
- Cloudflare Pages Function: `functions/api/send-order.js`
- Firestore rules: `firestore.rules`
- Local preview: `npm run preview`

No payment-gateway integration is included in this release.
