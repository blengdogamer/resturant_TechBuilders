هذا أرشيف تحديث فقط. فك الضغط فوق مجلد المشروع الحالي واسمح باستبدال الملفات ذات الأسماء نفسها. لا تستبدل public/js/firebase-config.js ولا public/js/telegram-config.js ولا ملفات الشعار.

الملفات المضافة/المعدلة:
- public/index.html, public/js/app.js, public/css/styles.css: اختيار الدفع، إنشاء فاتورة مستضافة وعرض رابطها.
- public/admin.html, public/js/admin.js, public/css/admin.css: تفعيل شام كاش من إعدادات المطعم، التحقق من حالة الدفع، وطباعة فاتورة للطلبات النشطة والأرشيف.
- functions/api/shamcash/create-invoice.js: إنشاء الفاتورة من الخادم مع إبقاء API token سرياً.
- functions/api/shamcash/invoice-status.js: الاستعلام والتحقق من الفاتورة من API.
- firestore.rules: السماح للعميل بقراءة طلبه فقط وتحديث بيانات رابط الفاتورة فقط؛ تحديث حالة الدفع الفعلية يبقى من لوحة المالك.

إعداد Cloudflare Pages بعد رفع التحديث:
1) Settings → Variables and Secrets → Add secret: SHAMCASH_API_TOKEN = مفتاح API الصادر من منصة shamcash-api.com.
2) تأكد أن ALLOWED_ORIGIN يساوي رابط موقعك بالضبط، مثل https://your-site.pages.dev (من دون / في النهاية).
3) Firebase → Firestore Database → Rules: انشر ملف firestore.rules المرفق.
4) لوحة الإدارة → إعدادات المطعم → فعّل شام كاش وأدخل account_id لحساب الاستقبال المرتبط، ثم احفظ.
5) عملة فاتورة شام كاش المدعومة في هذه النسخة هي الليرة السورية: ل.س أو SYP. إذا عملة الطلب غير ذلك، لن يظهر خيار شام كاش.

التشغيل:
- للعميل: يختار شام كاش ثم يرسل الطلب، وبعدها تظهر فاتورة مستضافة من ShamCash ورابط الدفع وملاحظة التحويل.
- في لوحة الإدارة: تظهر حالة الدفع، ويمكن للمالك الضغط على «تحقق من الدفع» لجلب الحالة الحقيقية من ShamCash. لا نعتبر الفاتورة مدفوعة قبل أن يرجع API حالة completed.
- الطباعة: زر «طباعة الفاتورة» موجود في بطاقة الطلب النشط وفي بطاقة الأرشيف. يطبع اسم المطعم، رقم الفاتورة، التاريخ، العميل، نوع الطلب، وسعر الوحدة والكمية وإجمالي كل صنف والضرائب والإجمالي النهائي.

ملاحظات مهمة:
- لا تضع SHAMCASH_API_TOKEN في JavaScript أو Firestore أو GitHub. خزّنه كـ Cloudflare Secret فقط.
- أرقام الطلبات الحالية ومحتويات Firestore لا تُحذف. التحديث يضيف paymentMethod/payment إلى الطلبات الجديدة فقط.
- هذا التحديث يستخدم واجهة https://api.shamcash-api.com/v1 كما في توثيق ShamCash الرسمي الذي أرسلته.
- لم يتم اختبار دفع حقيقي لأن ذلك يتطلب مفتاح API وحساب استقبال واشتراك الفواتير الخاص بك. تم فحص بناء JavaScript وصحة بنية ZIP محلياً.
